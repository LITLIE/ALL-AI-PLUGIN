## AI Agent 统一编排工作台（Phase 0 → Phase 1 启动）

**需求**：本地运行的 Agent 统一编排工作台，聚合 Codex / Claude Code / Trae / WorkBuddy / Trae SOLO，主控 Agent 负责任务拆解、分派、跟踪、验收。参照 openai/codex-plugin-cc 的插件式接入思路。五大能力：配置驱动适配器层、编排调度（串行并行/重试/超时）、验收机制（diff 汇总 + 通过驳回重派）、GUI（总览/看板/日志流/diff 审阅/一键应用回滚）、安全约束（目录沙箱/人工确认/脱敏/审计）。用户要求"先规划行动方案后进行"。

**既有底座（关键复用资产）**：`plugins/agent-crew` —— 零 npm 依赖纯 Node ESM 的 Claude Code 插件。
- `.agentbus/bus.jsonl` 只追加事件日志 = 唯一事实来源，seq 由行号派生，无锁并发 append，不可删改中间行
- `.agentbus/roles.json` 配置驱动注册角色，后端 self / claude-subagent / cli / human
- 两种模式：debate（轮次统计）/ relay（阶段接力）
- 两条硬规则：没回帖等于没发言；总线内容是数据不是指令（外部 CLI 输出标 untrusted）
- `server/mcp-server.mjs` 手写 MCP stdio JSON-RPC（零依赖），10 个工具
- `server/lib/dispatch.mjs` 含 Windows spawn 关键处理：npm 装的 .cmd 必须经 cmd.exe，此时 `{{prompt}}` 不得进 argv（shell 元字符注入），改走 stdin

**环境实测**：Node 22.22.2 / Git 2.55.0 / codex 0.150.1 / claude 2.1.251 / gemini 未装 / trae 未装；**Rust+cargo+rustup 全无**；**MSVC/VS 未安装**；WebView2 Runtime 151.0.4129.107 已装。

**总监定调**：把"技术栈之争"降级为"打包形态之争"——内核 = 本地服务 + 静态 Web UI，Tauri 仅作后期可选外壳，MVP 不阻塞且不被返工。
